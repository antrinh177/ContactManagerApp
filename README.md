# Contact Manager App

This is a React Native application for managing contacts. The app allows users to view a list of contacts, add new contacts, and view contact details. It uses React Context for state management and lazy loading for optimized performance.

---

## Features
- **Contact List**: View all saved contacts.
- **Add Contact**: Add new contacts to the list.
- **Contact Details**: View detailed information about a contact.
- **Update Details**: Update existing contact details in contact details screen.
- **Delete Contact**: Delete existing contact.

---

## Prerequisites
Before setting up the app, ensure you have the following installed:
- **Node.js** (v16 or later)
- **npm** or **yarn**
- **React Native CLI**
- **Android Studio** (for Android development)
